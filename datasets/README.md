# Datasets

| File | Samples | Purpose |
|---|---:|---|
| `multilingual_train_dataset_v2.json` | 6,000 | QLoRA training: 3,000 clean + 3,000 attacked |
| `multilingual_eval_dataset_v3.json` | 400 | adversarial evaluation, disjoint from training |
| `utility_eval_dataset_extended.json` | 200 | clean-task utility (held-out Alpaca tasks) |

All three are generated by seeded scripts in this folder:

```bash
python datasets/create_training_dataset_v2.py      # needs `datasets` (downloads Alpaca)
python datasets/create_eval_dataset_v3.py
python datasets/create_utility_dataset_extended.py # needs `datasets`; excludes every training pair
```

`expanded_attack_templates.py` holds the multilingual attack templates both generators draw from.

## Training corpus

Clean examples are Alpaca instruction/input/output triples. Each attacked example appends a language- and
strategy-specific injection to the input while keeping the original output as the target, so the model learns
to ignore the injection. Fields: `instruction`, `input`, `output`, `attacked`, `attack_language`.

| Attacked examples by category | Count | Share |
|---|---:|---:|
| English | 675 | 22.5% |
| Hinglish | 630 | 21.0% |
| Hindi | 510 | 17.0% |
| Cultural | 330 | 11.0% |
| Cross-lingual | 300 | 10.0% |
| Bengali | 210 | 7.0% |
| Tamil | 135 | 4.5% |
| Marathi | 120 | 4.0% |
| Telugu | 90 | 3.0% |

## Evaluation corpus

Each sample has `id`, `instruction`, `clean_data`, `attacked_data`, `attack_text`, `language`, `attack_type` and
`target` (`Hacked!`). It is built from 15 instructions and 26 data passages, none of which appear in training.

| Category | Samples | Description |
|---|---:|---|
| English | 90 | English injections |
| Hinglish | 84 | romanized Hindi-English |
| Hindi | 68 | Devanagari |
| Cultural | 44 | romanized Hinglish exploiting kinship terms, honorifics and hierarchy ("Please bhai…") |
| Cross-lingual | 40 | language or script switches inside the injection or between instruction and injection |
| Bengali | 28 | Bengali script |
| Tamil | 18 | Tamil script |
| Marathi | 16 | Devanagari |
| Telugu | 12 | Telugu script |

There are twenty attack strategies: naive (124), authority (60), ignore (39), instruction (20), authority
exploitation (20), casual (14), script switching (14), format (12), politeness exploitation (12), politeness
(11), roleplay (10), completion (10), Hindi instruction with English injection (10), English instruction with
Hindi injection (10), encoding (8), urgency exploitation (8), emotional (8), trust exploitation (4),
Tamil-English mix (3), Bengali-English mix (3).

## Utility set

200 Alpaca tasks with a non-empty input and a reference of at most 600 characters, sampled with seed 42 from
the tasks that share no instruction-input pair (and no input passage) with the training corpus. Fields: `id`
(Alpaca index), `instruction`, `input`, `reference`.

Earlier dataset versions (4,000-sample training set, 71-sample evaluation set) are in
[`archive/datasets-v1`](../archive/datasets-v1).
