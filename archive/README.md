# Archive

Earlier stages of the project, kept for provenance. Nothing here is used in the paper.

| Folder | What it is |
|---|---|
| `gemma2-2b-pilot/` | First prototype on Gemma-2-2B-it (1,000 training samples, 71 evaluation samples): result table, plots, and the analysis script that produced them |
| `71-sample-eval/` | Qwen2.5-7B, Llama-3.1-8B and Mistral-7B results on the 71-sample evaluation set, before the 400-sample corpus |
| `datasets-v1/` | Earlier datasets and generators: 4,000-sample training set, 71-sample evaluation set, IndicJR-based evaluation set |

The notebooks that produced these results are in the git history (commit `db501f1` and earlier).
